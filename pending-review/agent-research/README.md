# Agent Research Drafts
Tags: [research], [pending-review], [agent]

## Summary

This directory contains evidence briefs produced by the PostSingularity
research agent. Every generated file is non-canonical until a human verifies
the cited sources and accepts any proposed change.

The agent is designed to challenge assumptions rather than defend them. A brief
should distinguish observed developments from interpretation, connect evidence
to stable assumption IDs, and explain which canon files might eventually need
review.

## Review Rules

- Open and verify every cited source.
- Prefer primary sources, standards, papers, official releases, and regulatory
  records over summaries.
- Check publication dates and whether a source describes a demonstration,
  deployment, measured result, or prediction.
- Reject unsupported certainty, invented URLs, and conclusions that outrun the
  evidence.
- Update [`research/assumptions.json`](../../research/assumptions.json) only
  after review.
- Move accepted storyworld changes through the normal contribution workflow.

Generated reports may be revised or deleted without changing canon.
